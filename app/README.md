# krisphy app

Mobile-first React frontend for the Somjeed AI Phase 1 experience.

## Screens

- `ถ่ายสลิป` for image/OCR confirmation flow
- `พิมพ์ข้อความ` for Thai text-to-ledger draft flow
- `สรุปรายวัน` for nightly LINE summary preview

## Scripts

```bash
npm install
npm run dev
npm test
npm run build
npm run lint
```
